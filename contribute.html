How to contribute

Health Icons is made by volunteers from all over the world. Here's how you can get involved.

Get in touch

Join our open Slack channel by emailing contact@healthicons.org

Contribute icons

Browse the Figma and contribute icons in the "New icons" section. Please read the code of conduct and the styleguide (in the Figma) carefully before contributing.

Improve the website

Developers can browse the issues on Github and pick up projects to improve this website.

Code of conduct

We want Health Icons to be a welcoming, harassment-free community for everyone, whatever their background or level of experience. Before contributing, please read our code of conduct, which sets out the behavior we expect from contributors and maintainers and how to report a problem.
