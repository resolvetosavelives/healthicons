How to use icons

Health Icons are free to use in any project, with no credit needed. Download them one at a time, add them to your code with a package, or find them in Figma.

Styles and sizes

Every icon comes in two styles, outline and filled. The icons are drawn for 48px, and many also have a simpler 24px version that stays clear at small sizes. As SVGs they can be any size and any color.

Download from this website

Find an icon and click it to download it as an SVG or a PNG (48px or 96px, or 24px and 48px for the smaller version), or to copy its SVG code. Pick a color in the sidebar first and the downloads and code use that color.

Packages for your code

Building a website or app? Our packages let you import just the icons you need, in either style, at any size and in any color:

  • React
  • Vue
  • Svelte
  • JavaScript, for other frameworks and plain HTML pages

Figma plugin

Designing in Figma? The Health Icons Figma plugin lets you find icons and add them to your designs without leaving Figma.

All the icon files

  • Download every icon as SVG and PNG files in a ZIP file
  • The healthicons npm package has the same files, for projects that need image files: npm install healthicons
  • For React Native, there’s a community-made healthicons-react-native package (not made by the Health Icons team)

License

The icons are in the public domain (CC0), so you can use and change them however you like, in personal or commercial projects. See the licenses for details.
